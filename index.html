Immich Google Photos Sync

Immich Google Photos Sync is a privately operated application that transfers selected photo albums from a self-hosted Immich server to Google Photos.

Purpose

The application enables automatic photo slideshows on compatible Google-powered smart displays.

How It Works

Selected photographs are retrieved from a private Immich server and uploaded to an authorized Google Photos account using Google's Photos API.

The application runs locally on a Synology NAS. It is intended for private, personal use.
